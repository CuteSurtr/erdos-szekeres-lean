## 1. Question

ETVTHY20261113 §3 states the Δ-reduction conjecture. For 4 ≤ a ≤ n:

- **D(a, n; weak)**: every planar set (general position, distinct x) with no a-cap and no convex n-gon has a
  subset Δ that contains no (a−1)-cap and meets every convex (n−1)-gon.
- **D(a, n; strong)**: the same with Δ also containing no convex (n−1)-gon.

Weak Conj(n) is D(5, n; weak). Weak Conj(8) would give N5 ≤ 22 + 41 = 63; with weak Conj(7), N5 ≤ 54 and then
ES(8) ≤ 308 (ETVTHY §3.1). Before this record the evidence was random and targeted real sets, 31 random
signotopes and random walks; no case was decided exhaustively.

The task was an exists-forall search — *is there a configuration S that defeats every Δ?* — first on abstract
signotopes. Signotopes contain all point sets, so an UNSAT answer for m points is a theorem about all point
sets with m points; a SAT answer would be an abstract counterexample, to be tested for realizability.

## 2. Model and soundness (PROVED: written arguments; controls in §5)

**Signotopes.** A signotope on [m] = {0, …, m−1} is a map σ from increasing triples to {+, −} such that for
all i < j < k < l the sequence σ(ijk), σ(ijl), σ(ikl), σ(jkl) changes sign at most once. A point set P in
general position with distinct x-coordinates, sorted by x, gives the signotope σ_P(ijk) = sign of the
orientation determinant (+ = counter-clockwise = (p_i, p_j, p_k) is a cup). This is the standard fact used
already in ETVTHY20261113 (`abstract_conj.py`); control C1 re-checks it on 1,880 real sets.

**Notions in a signotope** (they are the definitions the CNF uses).
- k-cap / k-cup: a k-subset whose consecutive triples are all − / all +. (In a signotope every sub-chain of a
  cap is a cap: if (ijk) and (jkl) are −, the axiom forces (ijl) and (ikl) to be −.)
- convex k-set: a k-subset all of whose 4-subsets x < y < z < w satisfy σ(xyz) = σ(xyw) and σ(xzw) = σ(yzw).
  For points this is convex position: with x and w extreme in x-direction, "y lies in the triangle xzw" is
  σ(xyz) ≠ σ(xyw), "z lies in the triangle xyw" is σ(xzw) ≠ σ(yzw), and Carathéodory reduces convex position
  to 4-subsets.
- weak (c, d)-gon: a c-cap and a d-cup with the same two end points and no other common point (c + d − 2
  points). In every signotope a set is a convex k-set iff it is a weak gon (argument: the points above the
  chord of the two extreme points form a cap with them, those below a cup, by the 4-subset conditions;
  exhaustive control C5 on all 62 + 908 + 24,698 signotopes with 5, 6, 7 points).
- (a, n)-valid: no a-cap, and no weak (c, d)-gon with c + d − 2 = n and c ≤ a − 1. For a point set this says
  exactly: no a-cap and no convex n-gon (a convex n-gon whose upper chain has at least a points contains an
  a-cap).
- Δ ⊆ [m] **works** for σ (weak form) if no (a−1)-cap of σ lies inside Δ and every convex (n−1)-set of σ meets
  Δ; in the strong form, in addition, no convex (n−1)-set lies inside Δ.

**The statement D(a, n, m; form):** every (a, n)-valid signotope on m points has a working Δ. For m ≤ n − 2
there is no convex (n−1)-set and Δ = ∅ works, so only m ≥ n − 1 needs a computation.

**The CNF F(a, n, m; form)** (`tools/eager_cert.py`, class `Enc`; deterministic).
- Variables t(ijk), true = +. *Base clauses*: the signotope axioms (8 ternary clauses per 4-tuple); for every
  a-subset, "some consecutive triple is +"; for every n-subset G and every split of its inner points into a cap
  part A (|A| ≤ a − 3) and a cup part B, "not (min G, A, max G is a cap and min G, B, max G is a cup)".
- *Witness variables*, defined in one direction only: Y_K → "K is an (a−1)-cap" for every (a−1)-subset K;
  C_T → "T is a convex 4-set" for every 4-subset T; Z_G → C_T for all 4-subsets T of G, for every
  (n−1)-subset G.
- *Pool clauses*: for **every** subset Δ of [m] one clause "Δ fails":
  ⋁{Y_K : K ⊆ Δ} ∨ ⋁{Z_G : G ⊆ [m]∖Δ} (strong form: ∨ ⋁{Z_G : G ⊆ Δ}).

**Lemma S (soundness).** If some (a, n)-valid signotope σ on m points has no working Δ, then F(a, n, m; form)
is satisfiable. Hence: F unsatisfiable ⟹ D(a, n, m; form) holds for all signotopes, in particular for all
point sets with m points.

*Proof.* Put t := σ, Y_K := [K is an (a−1)-cap of σ], C_T := [T convex], Z_G := [G convex]. The base clauses
hold because σ is a valid signotope; the witness clauses hold by definition; the clause of Δ holds because Δ
fails for σ, so one of its witnesses is true. ∎

The converse also holds (a model's t-part is a valid signotope and every true witness is a real cap or convex
set, so every Δ fails); it is used only for SAT answers, and those are re-checked exactly outside the CNF
(`exact_sets`, `exact_delta`).

**Completeness of a case.** The base clauses alone, `base(a, n, m₀)`, being unsatisfiable means that no
(a, n)-valid signotope has m₀ points; validity is inherited by sub-configurations, so none has more. Then
"F(a, n, m) unsatisfiable for n − 1 ≤ m < m₀ and base(a, n, m₀) unsatisfiable" proves D(a, n; form) for all
signotopes and all point sets, of every size.

**Restricted variants** (all in `eager_cert.py`; the pool is still all subsets).
- `--allow X`: every pool clause of Δ gets the extra literals NA_p (p ∈ Δ), with NA_p → "p is not in the
  S-defined set X(σ)" (one direction). Unsatisfiable ⟹ every valid σ has a working Δ **inside** X(σ).
  X = `QQ`: points that start no (a−1)-cap or end no (a−1)-cap (Q ∪ Q′); `ends`: left or right ends of convex
  (n−1)-sets (E_L ∪ E_R); `rank`: Δ_R ∪ Δ_L of ETVTHY §3.2 (a j-cap and an (n+1−j)-cup end at p, or both start
  at p, for some 2 ≤ j ≤ a−1); `Q`: points that start no (a−1)-cap (negative control).
  Where "not in X" is a universal statement, it is expressed through over-approximating indicators
  (true whenever the object exists), again one direction each; the soundness proof is the same: assign every
  indicator its true value.
- `--must F`: every pool clause of Δ gets the literals MU_p (p ∉ Δ), with MU_p → "p ∈ F(σ)". Unsatisfiable ⟹
  every valid σ has a working Δ **containing** F(σ).
- `tools/thr_exact.py` (threshold rule, §7): exact two-sided definitions of "p starts / ends an (a−1)-cap" and
  one clause "Δ_x fails" for each of the m + 1 thresholds.

Every SAT answer of a restricted variant is re-checked from the model by plain enumeration (all caps, all
convex sets, then a small SAT over Δ with the restriction), so a SAT answer never rests on the encoding.

## 3. Method

1. **CEGAR as asked** (`tools/cegar.py`): pool of candidate index sets Δ; SAT-search a valid signotope in
   which every pooled Δ fails; compute a working Δ for it exactly; add it. For (a, n) = (5, 6) it ended UNSAT
   with pools of 11, 43, 104 and 243 sets at m = 8, 10, 11, 12 (130–164 with mirror images added) and was
   still running at m = 13 after 546 rounds. (Phase-2 note: no log of that run survives in W, so its outcome
   is unknown. The eager CNF of method 2 certified (5, 6) weak at m = 13 anyway, §4.1.) So the pool is a fixed fraction (about 4–6 %) of *all* subsets and
   grows like 2.3^m: **no bounded family of fixed index sets suffices**, and making the counterexample
   maximal (in its sets of caps and convex sets) before answering did not shrink the pool (228 against 243).
2. **Eager form** (`tools/eager_cert.py`): put all 2^m subsets into the pool at once. This is one CNF per
   (a, n, m, form), about ten times faster than the loop (m = 13: 13 s against more than 50 s), and it can be
   certified directly: CaDiCaL 2.1.3 writes an LRAT proof, cake_lpr checks it, the LRAT is deleted after the
   verdict and its hash is recorded. All "decided" claims below are of this kind.
3. **Structure tests**: the restricted variants of §2 ask where Δ can be found (inside which S-defined set,
   containing which S-defined set), the threshold CNF tests a concrete rule, and an exact minimax
   (`tools/online_game.py`) decides whether any left-to-right rule exists.
4. **Literature** (three web searches at 18:00 KST, not exhaustive): no statement of the Δ-reduction
   (splitting) formulation and no on-line version was found. (Superseded for the strong form and for a = n
   by the session's later literature check, NOVELTY20261113B; see §10.) Baek (arXiv:2206.04260) proves the case a = 4 of
   the Erdős–Tuza–Valtr conjecture by a different induction (his removed set makes the rest (n−1)-cup-free,
   not (n−1)-gon-free); Baek–Balko (SoCG 2025) say the conjectured values are known only in trivial cases and
   for a or b equal to 4; their "decomposable sets" are a different notion. SAT with signotope axioms for
   ES(6) = 17 is Scheucher's method. The value N(6, 5, 6) = 15 follows for point sets from ES(6) = 17 and the
   Erdős–Tuza–Valtr gluing argument, so only its certificate for signotopes is new here.
5. Cost grows by a factor 10–40 per extra point (weak (5,8): 0.1 s, 6 s, 242 s at m = 13, 14, 15), so the
   frontier is fixed by solver time, not by the CNF size. Clauses "every point lies on an (a−1)-cap and on a
   convex (n−1)-gon", valid for a minimum counterexample (Lemma 4), did not speed it up (§4.3).

### 4.2b Which part of each polygon Δ has to hit: the cup part suffices, the cap part does not

both containing u and v. The pair (u, v) is *saturated*: capB(u, v) + cupB(u, v) = n + 1 for the longest cap and
cup between u and v, and the cap parts (cup parts) of the gons on (u, v) are exactly the longest caps (cups)
from u to v. Three sharper forms of D(a, n) ask Δ to hit every gon in a prescribed part
(`tools/upper_exact.py`: one CNF with all 2^m subsets Δ, witnesses for "this chain is the cap/cup part of some
gon"; same soundness argument as Lemma S; SAT models re-checked by enumeration):

> **Lower-chain form.** Every set S with no a-cap and no convex n-gon has a subset Δ with no (a−1)-cap that

## 6. PROVED lemmas (valid for every signotope, hence for point sets)

Throughout, σ is an (a, n)-valid signotope on the ground set S; "gon" means convex (n−1)-gon; a gon is a cap
part with c ≤ a − 1 points and a cup part with n + 1 − c points, with common end points u < v.

**Lemma 1 (extension; ETVTHY 2.2 for general a).** If p starts an (a−1)-cap (p, d, …), then (o, p, d) is a
cup for every o < p, so every cup ending at p extends by d. Mirror: if p ends an (a−1)-cap (…, c, p), then
(c, p, q) is a cup for every q > p, so every cup starting at p extends to the left by c.

*Proof.* If (o, p, d) were a cap, o followed by the (a−1)-cap would be an a-cap. ∎

**Lemma 2 (layers).** Put L⁰ = S, Lⁱ⁺¹ = {p ∈ Lⁱ : p starts an (a−1)-cap inside Lⁱ} and Qᵢ = Lⁱ ∖ Lⁱ⁺¹. Then
1. no Qᵢ contains an (a−1)-cap;
2. every cup of S that ends at a point of Lⁱ has at most n − 1 − i points;
3. the right end of a gon whose cap part has c points lies in Q₀ ∪ … ∪ Q_{c−2}.

In particular the set E_R of right ends of all gons is contained in Q₀ ∪ … ∪ Q_{a−3}: **E_R is covered by
a − 2 sets without (a−1)-cap** (three 4-cap-free sets for a = 5, two cups for a = 4), and L^{a−2} contains no
gon. The Δ-reduction conjecture asks for one such set (it may use other vertices than right ends).

*Proof.* (1) A cap inside Qᵢ ⊆ Lⁱ would start at a point of Lⁱ⁺¹. (2) Induction on i; i = 0 is "no n-cup".
For i ≥ 1 let p ∈ Lⁱ start the (a−1)-cap (p, d, …) inside Lⁱ⁻¹. It is an (a−1)-cap of S, so by Lemma 1 every
cup C ending at p gives the cup C d, which ends at d ∈ Lⁱ⁻¹; hence |C| + 1 ≤ n − 1 − (i − 1). (3) The cup
part has n + 1 − c points and ends at the right end v; if v ∈ Lⁱ then n + 1 − c ≤ n − 1 − i, so i ≤ c − 2. ∎

**Lemma 3 (the two-sided cover and the set M).** Let L = L¹ (starts of (a−1)-caps), R = ends of (a−1)-caps,
Q = S∖L, Q′ = S∖R, M = L ∩ R. Q and Q′ contain no (a−1)-cap.
1. A cup of S with left end in R and right end in L has at most n − 3 points (it extends at both ends).
2. So a gon with left end in R and right end in L has a cap part of at least 4 points. **For a = 4 there is
   none: the two cups Q and Q′ together meet every gon.** For a = 5 these are the doubly hard (4, n−3)-gons of
   ETVTHY 2.6.
3. For a = 5: every gon contained in M is a (4, n−3)-gon, its right end starts no 4-cap inside M and its left
   end ends no 4-cap inside M. Hence **Q ∪ Q′ ∪ Q(M) meets every gon**, where Q(M) = {p ∈ M : p starts no 4-cap
   inside M}; these are three 4-cap-free sets.

*Proof.* (1) Lemma 1 at both ends gives a cup with two more points. (2) n + 1 − c ≤ n − 3. (3) By (1) a cup
inside M has at most n − 3 points, so a gon inside M has c = 4 and a cup part D with exactly n − 3 points.
If its right end v started a 4-cap (v, x, …) inside M, then D x would be a cup with n − 2 points, left end in
R and right end x ∈ M ⊆ L, against (1). A gon not inside M has a vertex in Q ∪ Q′. ∎

Numerically Lemma 3 gives nothing new for n = 8: 22 + 22 + 15 + 20 = 79 = 44 + f(6-cup, 5-cap), the bound
of ETVTHY 2.3. It is recorded because it locates the difficulty exactly: the gons inside M, and the
4-caps that run between the three pieces.

**Lemma 4 (minimum counterexamples, weak form).** Suppose D(a, n, m′; weak) holds for all m′ < m and σ is a
valid signotope on m points with no working Δ. Then for every point p and every Δ′ that works for σ − p there
are an (a−1)-cap K ∋ p with K∖{p} ⊆ Δ′ and a gon H ∋ p with (H∖{p}) ∩ Δ′ = ∅. In particular every point lies
on an (a−1)-cap and on a gon, and on such a pair with K ∩ H = {p}.

*Proof.* σ − p is valid with m − 1 points, so some Δ′ works for it. Δ′ contains no (a−1)-cap of σ (such a
cap avoids p), so, as Δ′ fails for σ, some gon H of σ misses Δ′; H is not a gon of σ − p, so p ∈ H.
Δ′ ∪ {p} meets every gon of σ, so, as it fails, it contains an (a−1)-cap K, and p ∈ K. ∎

**Lemma 5 (saturated pairs and descent).** For u < v let capB(u, v), cupB(u, v) be the numbers of points of a
longest cap and a longest cup from u to v.
1. capB(u, v) + cupB(u, v) ≤ n + 1, and the gons with end points u, v are exactly the unions of a longest cap and
   a longest cup from u to v when equality holds (the pair is then called saturated); there is none otherwise.
2. Let (u, v) be saturated with c = capB(u, v), and let v start an (a−1)-cap (v, x, …). Then for every longest
   u–v cup D the chain D x is a cup, capB(u, x) ≤ c − 1 (so c ≥ 3), and if capB(u, x) = c − 1 then (u, x) is
   saturated and D x is one of its longest cups. For c = 3 this always happens: D x is an (n−1)-cup.

*Proof.* (1) If capB + cupB ≥ n + 2, sub-chains with the same end points give a cap and a cup with n + 2 points
in all, a convex n-gon. A gon on (u, v) has a cap part with c′ ≤ capB and a cup part with d′ ≤ cupB points and
c′ + d′ = n + 1, so both are longest and the pair is saturated; conversely a longest cap and a longest cup of
a saturated pair meet only in u and v and form a gon. (2) Lemma 1 gives the cup D x with n + 2 − c points from u
to x; by (1) capB(u, x) ≤ n + 1 − (n + 2 − c) = c − 1, and capB ≥ 2. If capB(u, x) = c − 1 then
cupB(u, x) ≤ n + 2 − c = |D x|. ∎

Lemma 5 is what the lower-chain form of §4.2b can use and the cap-part form cannot: a cup part D whose right
end starts an (a−1)-cap is, up to its last vertex x, contained in the cup part D x of a gon of smaller cap type,
so a Δ that meets D x away from x meets D as well. (The classical choice, x itself, is exactly the wrong one.)

**Remark (colouring form).** D(a, n; weak) says: the points can be 2-coloured so that no (a−1)-cap is entirely
black and no convex (n−1)-gon is entirely white. The fractional relaxation is trivially feasible (weight ½ on
every point), so the content is integrality; §7 shows that the colouring cannot be produced on line.

What this says about a proof.
- **No left-to-right rule exists for a = 4.** In the on-line game the colourer must decide "p ∈ Δ?" when p
  arrives, knowing only the points to its left. For a = 4 the adversary wins: with 7 points for n = 5 (weak and
  strong form) and with 8 points for n = 6 (weak form, hence also the strong form). So no rule that decides
  from the points to the left works, even for 8-point configurations. For (5, 6) the colourer survives 8
  points (depth 8 decided after the cut-off by `online_game.py` alone, §4.4); larger depths were not
  decided. The classical cup–cap step (Δ = right ends
  of the longest cups) is an on-line rule, so the polygon version is of a different nature. By mirror symmetry
  the same holds for right-to-left rules. (COMPUTED, exact minimax, two independent programs; the adversary's
  configurations are abstract, and every signotope with at most 7 points is realizable.)
- **No canonical first layer.** The right ends of the (n−1)-cups must all be hit, and the classical choice is
  to put them all into Δ. That is impossible in general: for (5, 6) it fails from 10 points on (a real
  11-point set is verified), and for (4, 6), strong form, from 9 points on (real 9-point set). "Δ contains all
  points that start no (a−1)-cap" and "Δ contains all right ends of gons that start no (a−1)-cap" fail
  already for real 8-point sets.
- **Hitting every gon on its cap part is impossible, on its cup part it is not** (§4.2b). The cap-part form
  fails for real sets with 11 points (n = 6; only five 4-caps and 102 pentagons), 13 points (n = 8) and
  10 points (a = 4, n = 6, strong form), all verified from coordinates, and for 22 of the 435 real certificate
  sets of ETVTHY20261113. "Δ contains an end of every gon" fails for a real 9-point set. The cup-part form
  did not fail anywhere.
- **Δ needs vertices that are not ends of any gon**: for a = 5 from 12 points on for n = 6 and n = 7 and from
  13 points on for n = 8, each with a verified real point set (for n = 8: 13 points, 133 convex heptagons,
  3,916 working Δ, none inside E_L ∪ E_R). For a = 4, n ≤ 6 the ends always suffice (CERTIFIED for all sizes),
  but Δ needs points outside Q ∪ Q′ (real 10-point set in the strong form, real 11-point set in the weak
  form), although Q ∪ Q′ meets every gon (Lemma 3).
- **The rank localization survives**: Δ ⊆ Δ_R ∪ Δ_L (ETVTHY §3.2) is CERTIFIED for (5, 6) up to 13 points,
  (5, 7) up to 12 points and (5, 8) up to 13 points (the next size of (5, 7) timed out; no failure). The related
  restriction "Δ ⊆ ends ∪ interior cap vertices of gons" is CERTIFIED for (5, 6) up to 12 points, where "ends"
  alone fails, and for (5, 8) at 7–10 and 13 points (m = 13 run after the cut-off; 11 and 12 not run); "Δ ⊆ interior cup vertices" fails from 8 points on.
- **A threshold in x** (Δ_x = points of Q′ left of x together with points of Q from x on) works for every
  configuration with at most 8 points for (4, 6), at most 9 points for (5, 6) and all sizes for (4, 5); it
  fails for real sets with 9 and 10 points.
- **The inductive step "remove one point, extend any Δ′" fails**: there are 10-point sets for (5, 6) in which
  *every* point p has a working Δ′ of S − p such that neither Δ′ nor Δ′ ∪ {p} works for S (7 of 36 random
  samples, HEURISTIC frequency; one is realized and verified exactly). The rightmost point alone fails in this
  sense already for 8-point sets (7 of 58 samples).
- **No fixed family of index sets**: CEGAR pools grow like 2.3^m (§3); exact minimum families for (4, 5),
  strong form (CP-SAT on the full enumeration, `data/cover_number.log`): 1, 2, 4 sets for m = 5, 6, 7.
- **Canonical-vertex and row rules** (exhaustive over the 662 (4, 5)-valid signotopes with 5–7 points,
  `data/vertex_rules.log`): choosing from every gon its right end, left end, last or first cap vertex, or the
  vertex extreme for a rank statistic gives a cup in at most 547 of 662 cases; "leftmost / rightmost point of
  each β- or ω-level" gives a working Δ in at most 468 of 662.
- **No pointwise rule in Baek's coordinates** (`tools/baek_rule.py`, `data/baek_rule.log`; COMPUTED, exhaustive):
  for a = 4, p ↦ (α(p), β(p)) (longest cup ending at p with last edge of label 1; longest cup ending at p) is
  injective into a triangle of C(n, 2) cells. For n = 5 no set F of cells makes Δ = {p : (α, β)(p) ∈ F} work
  for all valid signotopes with at most 6 points, in the weak or in the strong form (SAT over the 2¹⁰ rules,
  212 signotopes).
- Not conclusive: greedy "Δ ∋ p iff necessary" in canonical orders other than x (`tools/order_greedy.py`)
  succeeds on all 83 random 10-point samples for (5, 6) for most orders — but so does the x-order, which the
  game shows cannot work in general for a = 4; random samples are too easy to say anything.

So a proof must be global: the statement is true for all small configurations, and every local or sequential
way of choosing Δ that was tried breaks between 7 and 13 points.
