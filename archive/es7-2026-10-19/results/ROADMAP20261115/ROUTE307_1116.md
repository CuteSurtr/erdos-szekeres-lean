### 1.3 The derivation

Let R be nonempty (empty R satisfies every bound below).
1. h(C) ≥ 33 (L3), h(F) ≥ 18 (L4), h(Lo) ≥ 14 (L5 + L6).
2. **Budget 33** (the 309 chain): if h(C) ≤ 33 then h(C) = 33 and (h(F), h(Lo)) ∈ {(18,15), (19,14)}; both excluded (L7).
   So h(C) ≥ 34.
3. **Budget 34** (the 308 chain): if h(C) = 34, then (h(F), h(Lo)) ∈ {(18,16), (19,15), (20,14)}; all excluded (L8, L9).
   So h(C) ≥ 35, |R| ≤ 119, |S| ≤ 1 + 187 + 119 = 307, **ES(8) ≤ 308**.
4. **Budget 35:** if h(C) = 35, then h(F) ∈ [18, 35 − h_Lo,min] where h_Lo,min = 70 − N66:
   - with N66 ≤ 56 only: (18,17), (19,16), (20,15), (21,14);
   - with N66 ≤ 55: (18,17), (19,16), (20,15);
   - with N66 ≤ 54: (18,17), (19,16).
   (18,17) and (19,16) are excluded (L10). If the remaining ones are excluded too, h(C) ≥ 36, |R| ≤ 118 and
   |S| ≤ 1 + 187 + 118 = 306.
5. **Forcing:** `Partition.forces_of_population_bounds` with 187 and 118 (positivity premise 1 ≤ 187 + 118) gives
   the threshold **187 + 118 + 2 = 307**: every 307 points in general position contain a convex octagon, **ES(8) ≤ 307**.
