# VERIFY_CTS6_REAL: independent check that CONJ-TS′(6) fails for real 13-point sets

## Claim checked

"CONJ-TS′(6) is false for real point sets at 13 points: the three abstract 13-point counterexamples lattice-nohyp,
lattice-hyp and flat-hyp are realized by the integer point sets in `*_real_s1.json`; 13 is the least size; on these real
sets weak D(5,6), the rooted form ROOT(6), the mirror form and ENV#(6) all hold." Filed by the main session; claimed label
EXACT (main session's own code only).

## Definitions used (read from the records, not from the filer's code)

- CONJ-TS′(n), terminal-safe, weak Δ, gon, h_U: `CONJTS_TEST.md` §2. Cap: for x-sorted a < b < c, orient(a,b,c) < 0.
- ROOT(n), ENV#(n), P4, the order ⊑ and ↑P4: `ROUND6.md` "Definitions" and `METHODS_SWEEP.md` §3.1. ↑P4 is the up-closure
  under the order generated by the stated steps (closure under single steps = closure under their transitive closure).
- Weak D(5,6) on a set: `DELTA2N20261113/README.md` §1 (D(a,n; weak)): a subset with no 4-cap meeting every convex pentagon.
- Mirror form: `VERIFY_ATN_MAIN.md` (the CONJ-TS′ test on the reflected set x → −x, relabelled by increasing x).

## Method (own code, written before reading the filer's scripts)

Script `/home/jay/research/data/roadmap-20261115/pm1115/v1/cts6-real-13/v1_check.py`
(SHA-256 `ff484002be80ae45beadcbb33a20c4fcb43b7b5aedfdf97d4dd5b4accf20fc6c`). Exact Python integers only. For each set it:

1. asserts every coordinate is a JSON integer, x is strictly increasing, and no triple is collinear (all 286 orientation
   determinants nonzero);
2. computes the 286 signs over lexicographic triples ('+' = orient > 0 = cup) and compares them with the model string;
   checks the model string is a signotope (all 4-tuples, at most one sign change) and equals the round-4 string in
   `conjts/analysis/n6_models.txt` (SHA-256 `1573b8af…6c3566d`, equal to `CONJTS_TEST.md` §8);
3. caps: a k-subset is a cap if every triple is a cap; the consecutive-triple definition is computed too and asserted
   equal on every subset examined;
4. convex position: exact monotone-chain convex hull (all points strict hull vertices), with the 4-point
   triangle-containment test computed as well and asserted equal on every subset examined;
5. validity: counts 5-caps and convex hexagons of S;
6. CONJ-TS′(6): counts 4-caps of S ending at r = 12; enumerates all 4,096 subsets A of U = S − r; A is a weak Δ if it has
   no 4-cap of U and meets every convex pentagon of U; A is terminal-safe if every 3-cap a < b < c in A has
   h_U(b,c) ≥ 4. h_U is computed twice (4-cap enumeration and a longest-cap dynamic program) and asserted equal;
7. weak D(5,6): all 8,192 subsets of S; also those containing both rightmost points;
8. ROOT(6): weak Δs A of S − r with A ∪ {r} 4-cap-free;
9. mirror form: reflects the coordinates (x → −x), re-sorts, and runs the same CONJ-TS′ test; separately, on the original
   labels, counts 4-caps starting at l = 0 and the weak Δs of S − l whose 3-caps a < b < c all have a 4-cap of S − l
   starting with (a,b) ("initial-safe"); the two computations agree;
10. ENV#(6) on S and on U = S − r: builds P4, the generating steps of ⊑ from every triple, the up-closure ↑P4, and counts
    the weak Δs whose 3-caps a < b < c all have (b,c) ∈ ↑P4.

A built-in self-test (5-cap on a concave parabola, 5-cup, a point inside a triangle, signotope test) runs first.
Runtime under 1 s per set, single thread, foreground.
