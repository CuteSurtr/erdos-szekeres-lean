# Mathematical companion

The formal exposition now lives in [math.md](../math.md) at the repository root.
It gives precise definitions, quantified statements, proofs and Lean declaration
correspondences for Suk, HMPT, the completed bound **ES(8) ≤ 314**, the
classical lower bound **ES(n) ≥ 2^(n-2) + 1** (so **ES(8) ≥ 65**), and the
remaining proposition for **313**, which is not proved.
