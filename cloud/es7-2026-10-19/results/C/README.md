# Task C: the mirror-symmetric class at 33 points (19–20 Oct 2026)

**Interim snapshot (23:15 KST): runs still in progress; numbers below Part 1 are not final.**

Question: is there a set of 33 points in general position, symmetric under a reflection,
with no 7 points in convex position? With 33 points the axis carries exactly one point
(off-axis points come in pairs; two axis points plus a third would be collinear only if
three lie on the axis, and 33 is odd). The axis point is either a hull vertex (sub-case (i))
or interior (sub-case (ii)); general position rules out the boundary.

Nothing here is a claimed theorem or counterexample. See "Status" at the end.

## Machine

the sibling tasks** (A, B, D). The load average was 80–100 for most of the run, so each of
our processes received about 12–20 % of a core. All CPU figures below are process CPU

## Encodings

All CNFs come from `tools/etv/gen_etv.py` (variables X(i,j,k), i<j<k, x-sorted points,
true = counterclockwise = cup; no 7-cap, no 7-cup, no convex 7-gon), regenerated by
`scripts/make_cnfs.sh`.

| file | meaning | vars / clauses |
|---|---|---|
| `hm33k7.cnf` | sub-case (i): `--hull --mirror`, point 1 = axis point sent to vertical infinity (X(1,i,j) true), points 2..33 paired i ↔ 35−i | 47,002 / 684,494 |
| `m33k7.cnf` | `--mirror`, points paired i ↔ 34−i, point 17 on the axis | 47,002 / 684,478 |
| `hm33k7.sub.cnf` | sub-case (i) after orbit substitution (`scripts/mirgen.py`) | 2,480 free orientation orbits, 535,454 clauses |
| `m33k7int.sub.cnf` | sub-case (ii): `m33k7` + orbit substitution + "axis point is not extreme" + y-reflection unit X(1,2,3) | 2,736 free orbits, 515,121 clauses |

* Orbit substitution: every orientation variable is replaced by the smallest index in its
  mirror orbit {X(i,j,k), X(m−k,m−j,m−i)}; the equivalence clauses become tautologies and
  are dropped, as are duplicate clauses. Auxiliary (cap/cup) variables are untouched.
* "Axis point c = 17 is not extreme" is two clauses: some X(i,c,k) with i<c<k is true (c is
  below a chord, so not on the upper hull) and some is false (not on the lower hull).
* The y-reflection negates every orientation; with A = U = 7 and no hull units it maps the
  sub-case (ii) CNF to itself, so X(1,2,3) = true is without loss of generality.
* Sub-case (i) uses the projective map (x,y) ↦ (x/d, 1/d), d = y0 − y, homogeneous matrix
  [[1,0,0],[0,0,1],[0,−1,y0]] of determinant +1. It fixes the mirror (x ↦ −x commutes with
  it), sends the top axis point p to vertical infinity and lines through p to vertical
  lines, and preserves orientations of triples avoiding p (all d > 0). Convex 7-gons through
  p become 6-cups of the other 32 points.

The encodings are **unverified** in the sense of `plan/es7_critique.md` item 4: the
signotope axioms, one-directional cap/cup auxiliaries, gon clause, mirror identification,
hull-plus-mirror projective step and interior clause are tested below, not proved.

## Part 1: encoding validation (passed)

`scripts/validate.py` (report `logs/part1_validate_report.json`, seed 1):

* 1,000 random exactly mirror-symmetric 33-point integer sets in general position with one
  axis point (500 interior, 250 top, 250 bottom; |coordinates| < 10^6, all x distinct).
  * x-sorted orientations satisfy **every** orientation-only clause of `m33k7.cnf`
    (332,800 clauses: signotope axioms + identification clauses = sign rule): 1000/1000.
    Direct identity check X(i,j,k) = X(34−k,34−j,34−i): 0 violations.
  * The interior clause pair holds exactly for the interior sets and fails for the
    extreme ones: 1000/1000.
  * Interior sets satisfy every orientation-only clause of `m33k7int.sub.cnf`: 500/500.
  * Extreme sets (bottom ones reflected to the top) in the projective hull frame satisfy every
    orientation-only clause of `hm33k7.cnf` and `hm33k7.sub.cnf`: 500/500 each; sampled
    orientation preservation of the map: 0 mismatches in 100,000 triples.
  * Full CNF under the set's orientations: UNSAT exactly when the set has a convex 7-gon
    (cgon count) for 200/200 sets (`m33k7`), and UNSAT for 100/100 hull-frame sets. Random
    sets all have many 7-gons (minimum 25,411), so this only checks gon detection.
* Small-k equivalence (2,000 random mirror sets per row; "CNF SAT under the orientations"
  must equal "no convex k-gon" by exhaustive Python check):

  | instance | agree | k-gon-free sets among them |
  |---|---|---|
  | N=7, k=5, 1 axis point, non-hull | 2000/2000 | 229 |
  | N=7, k=5, hull frame | 2000/2000 | 56 |
  | N=8, k=5, 0 axis points | 2000/2000 | 164 |
  | N=9, k=5, both frames | 2000/2000 each | 0 (ES(5) = 9) |
  | N=11, k=6, non-hull | 2000/2000 | 17 |
  | N=11, k=6, hull frame | 2000/2000 | 18 |

Controls (`scripts/controls.sh`, `logs/part1_controls.log`):

* k = 5: `m8k5` (8 points, 0 axis points) is SAT, and an explicit mirror-symmetric
  pentagon-free 8-point set is in `sets/control_k5_mirror8_pentagon_free.txt` (exactly
  verified). `m9k5`, `hm9k5` and `m9k5.sub` are UNSAT, each with an LRAT proof that
  lrat-check VERIFIED.
* k = 6, 17 points, one axis point: `m17k6`, `hm17k6` and their orbit-substituted versions
  are UNSAT, each LRAT VERIFIED. **This control is weak**: a mirror-symmetric hexagon-free set
  has at most 5 pairs. Proof: sort the points right of the axis by y. If some triple a,b,c
  has b right of chord ac, then a,b,c and their mirror images form a convex hexagon; otherwise
  all those points lie on one convex chain, so 6 of them form a convex hexagon. This also
  explains the "m16k6 UNSAT" surprise of critique item 8 and the side runs in
  `logs/part1_k6_side_instances.log` (m12k6 … m16k6 UNSAT; hm12k6, i.e. 5 pairs plus two
  axis points one of which is a hull vertex, is SAT). An exactly verified mirror-symmetric
  hexagon-free 11-point set is in `sets/control_k6_mirror11_hexagon_free.txt`.
* Positive control at k = 7: the mirror-symmetric classical 32-point set
  (`tools/decomp/mirror.py`, rotated by `tools/etv/mircheck.py`) has **0 axis points**,
  which is the case `gen_etv.py --mirror` encodes for N = 32 (no fixed index). Its
  orientations satisfy `m32k7.cnf` and `m32k7.sub.cnf` (CaDiCaL SAT under the 4,960
  orientation assumptions). The 2-axis-point case at 32 points is not encoded except
  through `--hull` (one axis point a hull vertex), which was not needed here.
