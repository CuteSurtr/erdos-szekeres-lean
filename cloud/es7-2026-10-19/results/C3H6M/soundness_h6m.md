# Addendum to `results/C3-S/soundness.md`: Lemma H6M (mirror reduction below H6)

Paths are relative to `cloud/es7-2026-10-19/`. This addendum uses the class, the normal form and
Lemmas 1–5 of `results/C3-S/soundness.md` as stated there. It replaces the sentence of
`soundness.md:78–79` ("This mirror map is only used under H3; … which is not used") when the cut
is taken with the H6M reduction. Without the reduction, `soundness.md` is unchanged.

Notation: m = 11, n = 3m = 33, labels 0..n−1 read from the line l, σ_i = [x_i < 0],
R(i) = (i − m) mod n, σ_{r+m} = 1 − σ_r, σ_{r+2m} = σ_r. For a top case H6(a, s) we have
1 ≤ a ≤ 5 and s = σ_a. A layer-2 option O below H6(a, s) is either a one-orbit layer {(r, None)}
or a two-orbit layer {(b, σ_b), (c, σ_c)} with b < c, where r, b, c ∉ {0, a}. There are
9 + 36·4 = 153 options. key(O) is the tuple of the pairs (r, σ) sorted by r, with None written −1.

## Lemma H6M

Fix H6(a, s). For r ∉ {0, a} and σ ∈ {0, 1, None} let

  φ_{a,s}(r, σ) = ((a − r) mod m, σ ⊕ [r < a] ⊕ [s = 0]),  with None ⊕ x = None,

and apply φ_{a,s} to a layer elementwise. Let S be in the class, with a canonical labelling
(Lemma 2) in case H6(a, s) and layer path (L_1, L_2, L_3, …). Let M be the reflection in l. Then
M(S) is in the class, and it has a canonical labelling in the same case H6(a, s) with layer path
(L_1, φ_{a,s}(L_2), φ_{a,s}(L_3), …).

**Proof.** I checked each step myself; the steps follow `results/C3PLAN/PLAN.md` §3a and
`results/C3AUDIT2/REPORT.md` §1.

1. *M(S) is in the class.* M R M = R⁻¹, so M(S) is invariant under the group generated by R.
   M is affine and bijective, so general position and the absence of 7 points in convex position
   are kept. The centre c lies on l, so M fixes c.
2. *First labelling of M(S).* Keep l. M maps y/x to −y/x, so label i becomes n − 1 − i, and every
   point changes side of l, so every σ flips. Now turn l by a small angle, just past the line of
   the point labelled n − 1 (the image of old label 0). Only this line is crossed, so that point
   alone changes side. The labels become i ↦ (−i) mod n. σ'_0 = 0, and σ'_j = 1 − σ_i for the
   label j = (−i) mod n of every other point. Residue r goes to label 3m − r = (m − r) + 2m, so
   σ'_{m−r} = σ'_{(m−r)+2m} = 1 − σ_r. This is Lemma 5 word for word; that proof never uses
   |H| = 3. The hull of M(S) is the image of the hull of S: orbits 0 and t := m − a, with
   σ'_t = 1 − s. Because t ≥ 6 > ⌊m/2⌋, this labelling is not yet canonical.
3. *Move label 0 to the point labelled t* (Lemma 2(a)). Turn l to just before the line of label t.
   l turns by less than 180° and crosses exactly the lines of labels 0..t−1. Exactly those points
   change side, so their σ flips. Every other σ is kept. New label i is old label (i + t) mod n.
   - New label 0 is old label t (not crossed). Its σ is 1 − s.
   - New label a is old label a + t = m (not crossed, since m > t). Its σ is σ'_m = 1 − σ'_0 = 1.
     So the new hull is orbits 0 and a, with the same a ≤ 5.
   - A residue r ∉ {0, a} of S goes to residue r' = m − r after step 2 and then to
     ρ = (r' − t) mod m = (a − r) mod m. The new label ρ is old label ρ + t.
     If r < a, then ρ = a − r and ρ + t = m − r = r' ∈ (t, m). That label is not crossed, and
     its σ is σ'_{r'} = 1 − σ_r. If r > a, then ρ = m + a − r and ρ + t = 2m − r = r' + m ∈
     [m + 1, 2m − 1]. That label is not crossed either, and its σ is σ'_{r'+m} = 1 − σ'_{r'} = σ_r.
     So σ_ρ = σ_r ⊕ [r < a].
4. *Fix σ_0* (Lemma 2(b)). If the new σ_0 = 1 − s equals 1, that is if s = 0, apply p ↦ −p. This
   keeps every label and the hull, and flips every σ. Afterwards σ_0 = 0 and the other hull residue
   is a, with σ_a = 1 ⊕ [s = 0] = s. So the labelling is canonical (label 0 on the hull, σ_0 = 0,
   a ≤ ⌊m/2⌋) and in case H6(a, s). Every residue r ∉ {0, a} of S is now residue
   (a − r) mod m with σ equal to σ_r ⊕ [r < a] ⊕ [s = 0], which is φ_{a,s}(r, σ_r).
5. *Layers.* M is affine. Relabelling and p ↦ −p do not change the point set; p ↦ −p maps the
   set onto a congruent set and maps each layer to the image layer. So the j-th convex layer of
   M(S) is the image of the j-th layer of S, and its residues and σ are given by φ_{a,s}. The top
   layer maps to the top layer {(0, 0), (a, s)}. A one-orbit layer carries no σ in its node
   (Lemma 3), and φ keeps None. ∎

**φ_{a,s} is an involution on the 153 options.** If r < a, then ρ = a − r ∈ (0, a), so ρ < a.
If r > a, then ρ = m + a − r ∈ (a, m), so ρ > a. Hence [ρ < a] = [r < a], (a − ρ) mod m = r, and
the σ terms cancel. ρ is never 0 or a. So φ maps options to options (b ≠ c stays b ≠ c) and
φ ∘ φ = id. Exactly 9 options are fixed by φ: the one-orbit layer with 2r ≡ a (mod 11), and the
8 two-orbit layers {b, c} with b + c ≡ a (mod 11) and σ_c = σ_b ⊕ [b < a] ⊕ [s = 0]
(4 pairs {b, c}, 2 values of σ_b). This is checked by enumeration in `logs/test_tree.json`.

**Corollary (cover below H6).** Let kept(a, s) be the set of options O with
key(O) ≤ key(φ_{a,s}(O)). key is injective and φ_{a,s} is an involution, so kept(a, s) has
exactly one member of each pair {O, φ(O)} with O ≠ φ(O), plus every fixed option: 72 + 9 = 81
of 153 options (5 of 9 one-orbit, 76 of 144 two-orbit). For every S in the class in case H6(a, s),
either S's own layer 2 is in kept(a, s), or φ_{a,s}(L_2) is, and then M(S) with the labelling of
the lemma is a set of the class in case H6(a, s) with layer 2 in kept(a, s).

The argument uses m odd (a ≠ m − a) and the a ≤ ⌊m/2⌋ rule of Lemma 2(c). Both hold for m = 11.
It uses the M(S) side once per H6 subtree, so it must not be combined with another reduction that
picks between S and M(S) inside the same H6 subtree, unless that reduction has its own proof.

## Theorem (cover, with the reduced cut)

Let the **reduced layer tree** be the layer tree of `soundness.md` with these children:
- root: the 11 top cases H3, H6(a, s);
- H3: `h3_layer2_kept(11)` (Lemma 5, 100 of 190 options);
- H6(a, s): kept(a, s) (Lemma H6M, 81 of 153 options), for each of the 10 cases;
- every node of depth ≥ 2: every next layer on the unused residues (Lemma 4, unreduced).

If every node of a set N has an UNSAT node CNF (base + its units), and every root-to-leaf path of
the reduced tree passes through a node of N, then the class is empty. The trusted parts are the
base encoding, Lemmas 1–5 and H6M (paper proofs, validated mechanically), and the proof checkers.

*Proof.* Let S be in the class. Choose a canonical labelling (Lemma 2). If S is in case H3, let
T = S or M(S) as in Lemma 5. If S is in case H6(a, s), let T = S when L_2(S) ∈ kept(a, s), and
otherwise T = M(S) with the labelling of Lemma H6M. Then T is in the class, and T's layer path
starts with a top case and a kept layer 2. Below depth 2 the reduced tree has all children, and
Lemma 4 shows that every next layer of T is a child. So T's path is a root-to-leaf path of the
reduced tree, and it passes through some node ν ∈ N. By the Theorem of `soundness.md`, the true
assignment of T's labelling satisfies the base CNF and the units of every node on T's path, so
ν's CNF is satisfiable. This contradicts the choice of N. ∎
