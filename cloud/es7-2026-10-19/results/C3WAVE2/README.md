# C3WAVE2: survey of the untouched depth-2 roots of the 3-fold class

`roots.tsv` lists the 1,349 depth-2 roots of `results/C3-S/manifest_depth2.tsv` (1,630 in all) that no record of wave 1 (`results/C3WAVE1/C00` to `C23`, `out.jsonl`, 23,285 records) touched (a record touches root R if its node is R or starts with `R_`), in manifest order, renumbered idx 0..1348. Machines K00 to K39 take idx ≡ i (mod 40) and give each root a 10-minute slice (`TASK.md`). The 281 touched roots, some closed and some partial, are left for a later wave that resumes from the wave-1 records.
