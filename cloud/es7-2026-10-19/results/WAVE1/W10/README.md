## Incident (no effect on the result)
In the first run, the solver wrote leaves.jsonl inside the repo, and the periodic
`git pull --rebase --autostash` replaced that file, so records went to an unlinked inode. I
recovered the file through /proc/PID/fd (171 complete records), stopped the run, and resumed
it with its output in /home/user/work/out, which is copied into the repo before each commit.
The cubes in flight at the restart were solved again; their first, unrecorded attempts are
missing from the CPU total, which therefore understates it by at most a few core-minutes.
